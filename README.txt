                    Created by Kimhong, Devs
============================================================

Thank you for using Audify!
Audify is a standalone desktop audio recorder for Windows that allows
you to record system loopback audio (what you hear) and your microphone
directly to studio-grade MP3 files. No Python or extra software required.

------------------------------------------------------------
HOW TO RUN AUDIFY
------------------------------------------------------------
1. Extract all files from this ZIP archive to any folder on your computer
   (for example, your Desktop or Documents folder).
2. Double-click "Audify.exe" to launch the application.

------------------------------------------------------------
WINDOWS DEFENDER / SMARTSCREEN WARNING (WHAT TO DO)
------------------------------------------------------------
Because Audify is an independently developed application that is not
digitally signed with an expensive commercial enterprise certificate,
Windows Defender SmartScreen may show a blue prompt saying:

   "Windows protected your PC
    Microsoft Defender SmartScreen prevented an unrecognized app from starting."

This is completely normal for open-source / independent software.
To run Audify:
1. Click the underlined link: "More info"
2. Click the button: "Run anyway"

Audify will launch immediately and Windows will remember your choice.

------------------------------------------------------------
QUICK START GUIDE
------------------------------------------------------------
- Audio Sources:
  * Select your System Output (speakers/headphones) from the dropdown.
  * Check "Record Mic" if you want to include microphone audio.
- Start / Stop:
  * Click the large circular Record button in the center, or
  * Press the global shortcut: Ctrl + Shift + R (works from anywhere,
    even while playing games or working in other apps!).
- Recordings Location:
  * All MP3 recordings are automatically saved to your Music folder:
    C:\Users\<YourUsername>\Music\Audify\
  * You can view past recordings via the History button or change the
    output directory anytime.
- System Tray:
  * Closing the window keeps Audify active in the system tray (near the clock).
  * Right-click the Audify tray icon to Start/Stop recording or Quit.
